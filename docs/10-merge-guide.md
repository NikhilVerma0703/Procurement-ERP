## 4. Cut-over

Run on a Neon branch first, then on production, by hand:

1. **The final backup.** Take the old site's last backup (plan, Step 0) into `data/erpnext-backup/`. The one in hand is from 16-11-2026. Any PO raised after that is only in a later backup.
2. **The schema.** Run `npx prisma db execute --schema prisma/schema.prisma --file scripts/NNNN-purchase-module.sql`, then `npx prisma generate`. Run its CHECK queries.
3. **The data.** Run `npm run import:erpnext` from a machine that has the backup, with `DATABASE_URL` pointing at the ERP database. The importer:
   - empties and loads only the module's tables, in one transaction (all or nothing). It finds them by the `purchase_` prefix, which no ERP table uses.
   - truncates without `CASCADE`, so Postgres refuses rather than empty another module's table that points at these.
   - refuses to reload once anything was made in the module (POs, suppliers, items, addresses, contacts), unless forced.
4. **The files.** The importer has put the 5 attachments and the logo into `purchase_files` with the data.
5. **The checks.**
   - The import's reconciliation must say "✓ Import matches the backup".
   - Run `npm run golden`: 3,199 POs, 0 unexplained differences, as here.
   - Run `npx tsx scripts/purchase/check-sheets.ts`: 16 of 16 sheets match.
6. **The logins.** In Users & Roles, an admin gives the buyers the `PURCHASE` role.
7. **First use.** Work through the acceptance checklist ([11-acceptance.md](11-acceptance.md)) on production with the Procurement Manager. Then switch the old site off.

## 5. Decisions the merge needs

1. **Who approves.**
   - The old workflow: "Purchase Head" raised a PO, "Admin" approved it.
   - In practice, over the last 12 months both buyers (Thiru R, Althaf) held both roles. They raised 1,629 POs and approved 1,441 between them.
   - Options:
     - **a.** `PURCHASE` may also approve, as practised.
     - **b.** Approval stays with the ERP's `ADMIN`.
     - **c.** A second role, `PURCHASE_APPROVER`.
2. **Attachment size.** The old site allowed 10 MB per file. The Main ERP's Vercel limit allows about 4 MB per upload (the Lab module uses 4,000,000 bytes). The 5 files on old POs are 344 KB at most. Recommendation: 4 MB, as Lab.
3. **Which mailbox sends PO emails.** The writer's own SMTP settings, else the ERP's global ones (the Main ERP's rule, as recommended); or one purchase mailbox for everyone.
4. **The three notifications** stay off (the old site last sent one on 21-09-2024) unless you switch them on.
